# ASCII Jellyfish 🪼

Colourful, pulsing ASCII jellyfish drifting through a glowing sea with bubbles and plankton.
A rainbow name types out underneath. Pure HTML/CSS/JS — no build step.

Change the name: edit `const NAME = "MITHUN";` near the top of `index.html`.

## Put it on GitHub (shareable link)
1. Create a new repo (e.g. `jellyfish-ascii`).
2. Upload `index.html` and `README.md`, commit.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Link: `https://<your-username>.github.io/jellyfish-ascii/`
