# Mithun — ASCII Plane Animation ✈

An animated ASCII-art plane flying across a night sky with the name **Mithun** underneath.
Pure HTML/CSS/JS — no build step, no dependencies.

## Put it on GitHub (and get a shareable link)
1. Create a new repository on github.com (e.g. `mithun-plane`).
2. Upload `index.html` and `README.md` (Add file → Upload files → Commit).
3. Go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After a minute your link will be: `https://<your-username>.github.io/mithun-plane/`
